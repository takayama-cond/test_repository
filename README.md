# 指示：以下の内容を元に、Webシステムを作成してください。

# 作るもの：本の貸出状況を管理するWebシステム
- 目的：本を借りる各自の私用スマホからも状況確認を可能にしたい。社用GoogleアカウントおよびGoogleドライブは存在するが、私用スマホからGoogleアカウント使用禁止のため、切り離した環境としたい。Webで使える環境とする。
- 実行環境：iOS、Android、Windows
- Webシステム機能：本を借りる人ごとにログインIDを用意。借りる予定日、返却予定日の参照、登録、更新が可能。
- 同時接続：10名以下
- Webシステム運用コスト：できるだけ無料に近づけたい。

# 細かい仕様
- IDの発行方法：管理者権限のアカウントのみで作成可能
- 管理者権限アカウントができること：本の登録、一般権限アカウントの作成
- 本の管理：本1冊につきタイトル、著者。重複登録は不可とし、1冊を同時貸出不可。
- 予定の重複：1名が本2冊以上の貸出可能
- 予定と実績：それ入力可能とする
- 参照範囲：管理者権限および一般権限で、本の予定日・実績日を参照可能。
